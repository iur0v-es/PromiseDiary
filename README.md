## Запуск

Нужны Python 3.10+ и браузер.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
fastapi dev app/main.py
```

Открыть http://127.0.0.1:8000.
Остановить сервер можно через Ctrl+C.

После установки зависимостей интернет для работы не нужен.

## Возможности

- Создание, редактирование, закрытие и повторное открытие дел.
- Поиск по названию и описанию, фильтрация по статусу.
- Просмотр по сроку завершения за день, неделю и месяц.
- Комментарии с отметками времени.
- Сохранение черновиков и отмена несохранённых правок.

## Реализация

Сервер — FastAPI, проверка данных — Pydantic.
Данные хранятся в SQLite, интерфейс написан на HTML, CSS и JavaScript.

База создаётся автоматически в `data/diary.sqlite3`.
Изменения выполняются в транзакциях.
Некорректные записи пропускаются с предупреждением,
исходные данные не удаляются.

Черновики сохраняются в localStorage при вводе.
Для восстановления нужен тот же браузер и адрес приложения.
При очистке данных браузера черновики удаляются.

Неделя начинается в понедельник. Периоды включают обе границы.
Время комментариев хранится в UTC и показывается в местном времени.

## Тесты

```bash
python -m unittest tests.test_repository -v
```

Проверяют повреждённые записи и сохранность данных.
Используется временная база.

## Ограничения

Приложение предназначено для локального использования.
Синхронизации, истории версий и защиты от одновременных
правок в нескольких вкладках нет.
Физическое повреждение файла базы требует резервной копии.
